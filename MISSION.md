# Mission — Cognitive Architecture for a Captain

## Why I'm learning this

I run a crew of coding agents (the "herdr crew") and a cabin-agent simulation with a
reasoning brain inside it. I want to understand **cognitive architecture** well enough
to:

1. Talk about what my crew actually does (BDI, CoALA, agents + memory + tools) without
   getting lost in jargon.
2. Read the Python brain my agent `mind` published (`cogarch_bootstrap.py`) and the
   knowledge page it wrote, and be able to explain both to someone else.
3. Make better calls as "captain": what to automate, what to delegate, what looks
   fragile.

## Depth preference

- **Medium depth, not deep dives.** I want the shape of the architecture and the "why",
  not every equation.
- **Python-first.** Explain through the actual code that exists in the repo.
- **Example-driven.** Show me the real loop, then the theory name for it.

## Success looks like

By the end of a few lessons I can point at `cogarch_bootstrap.py` and explain each
moving part, tie it to the cabin sim, and say what an agent with beliefs/desires/
intentions actually does differently from a plain chatbot.

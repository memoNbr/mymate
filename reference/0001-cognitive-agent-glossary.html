Reference · Cognitive Agent Glossary

The raw units of the first lesson. Quick-reference sheet; open it when a term makes you blink.

Core terms

TermPlain-English meaningWhere it shows up in our code
Cognitive agent An LLM wrapped in a persistent architecture: memory + a reasoning loop + tools, so a stateless model can hold state and act over time. The whole CogAgent class.
Beliefs What the agent thinks is true right now (perception distilled). self.beliefs + perceive().
Desires Things the agent could want to do, each with a score. The GOALS dict's desire(x) lambdas (0.5 / 0.8 / 0.9).
Intention The strongest valid desire, committed — the one the agent will act on this cycle. self.intention, set in cycle().
Perception → belief Raw observation in, structured belief out (here: token primes). perceive(observation).
Act hook The pluggable "hands" of the agent — what it does once it intends something. act_fn / default_act() / your own override.
Memory Recent trail of observations, kept short and full. self.memory (last 8) + priors on disk.
Priors Carried-over knowledge/state (e.g. trust, ride count) that survives restarts. priors JSON in cogarch_state.json.
CoALA A research frame: agents = memory × action space × reasoning loop. Good mental model for what our agent is. Concept only (see lesson + resource list).
BDI Belief–Desire–Intention: the classic goal-driven agent cycle we implement. cycle(): perceive → score desires → commit → act.
Sampling cadence How often the loop breathes (time between cycles). --cadence 0.2 (seconds).
Trust / confidence A running score of how confident the agent is in its loop, blended with priors. sample() + update_trust().
EWMA Exponentially weighted moving average — a 60/40 blend of new evidence and carried priors. 0.6*conf + 0.4*p_t in update_trust.
OpenAI-compatible The one wire format (POST /chat/completions, Bearer key) that works with OpenAI, ollama, llama.cpp, vLLM, Google's /openai surface. llm_call().

One-sentence refreshers

  • Why memory matters: an LLM forgets everything between calls; memory + priors give it a past.
  • Why intention matters: desires are noise; committing to the strongest one makes the agent actually do a thing each cycle.
  • Why a model-agnostic loop is smart: you can swap the brain (OpenAI, ollama, Gemini, Groq…) without touching the architecture.
  • Why trust blends priors: 60% new evidence + 40% history means it learns, but doesn't swing wildly.
